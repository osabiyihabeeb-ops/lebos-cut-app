# ✂️ Lebo's Cut Salon

A modern booking website for Lebo's Cut Salon - Ibadan, Nigeria.
Customers can view services & prices, book a session, and see real cuts in the gallery.
Admin can approve or reject bookings.

Live Demo: Coming Soon

## ✨ Features

- **Home Page** - About the salon, popular services, why choose us
- **Booking Page** - Styled like the viral video:
    - Yellow banner with Chat on WhatsApp
    - Services & Prices grid (black cards, yellow when selected)
    - White booking form with selected service + total
    - Booking saves without WhatsApp redirect
- **Gallery Page** - Real cuts with Like ❤️ and Comments 💬
- **Admin Page** - View all bookings, Approve / Reject
- **Footer** - Auto-updates to current year
- **External Styling Only** - All styles in `App.css`, no inline styles

## 🛠️ Tech Used

- React + Vite
- JavaScript (JSX)
- CSS (External File Only - `App.css`)
- LocalStorage - Bookings, Likes & Comments are saved in browser
